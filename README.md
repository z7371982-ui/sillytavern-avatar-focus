# 头像取景与头像库

## 1.3.2：一键备份全部图库

**入口：扩展设置 → 头像取景与头像库 → 全部图库备份。** 不需要逐个打开角色。

1. 原设备点 **导出全部 ZIP**，得到一个 `.stafe.zip` 文件。
2. 把文件传给另一设备，点 **导入全部 ZIP**。
3. 核对每份图库的接收对象，再点 **确认合并**。

导入确认页支持：

- 找到同类型、同头像文件名及同名称的对象：预选关联，仍需你确认。文件名或名称变化、同名不确定时不强行猜测。
- 没找到对应对象：默认 **保留待关联**；可改为 **跳过**，也可选择 **手动选择接收角色 / 用户**。
- **未匹配：全部保留 / 全部跳过**，几百个角色也不用逐个点。跳过仅指本次不导入，不删除备份包或原图库。
- 手动选择支持输入头像文件名，从候选列表选择；角色图库与用户图库分开，不跨类型误关联。

**管理待关联图库**：查看以前保留的图库，手动关联到已有对象。成功后图片移入目标图库并去重，不额外留一份待关联副本；跳过则继续留在原处。不会自动创建角色卡。

全部 ZIP 包含：当前浏览器保存的所有 char / user 图库、待关联图库、原图、每图取景/缩放/旋转/饱和度、原头像的独立调整、各角色轮换开关/间隔/方式、扩展手势开关。**不包含酒馆角色卡、聊天或其他扩展数据，也不会自动下载未加入图库的头像原图。** 导入不会替换当前头像，导入后想换图仍点“使用这张”。

已有角色的轮换设置默认保留；可勾选覆盖。没有本地轮换设置的图库会接收备份设置，计数从 0 开始，不恢复历史计数和随机队列，以免导入立即触发轮换。长按、三击、魔法棒及长按时间的全局设置，只有勾选恢复才改变。

用户头像候选来自酒馆当前已加载的头像界面。未显示的用户头像不猜测匹配，可先打开酒馆用户头像列表后重新进入导入/待关联管理。角色候选来自当前酒馆已加载的角色列表。名称和文件名只是匹配提示，跨设备仍请核对，特别是重名卡。

全量备份最多 5000 份图库、20000 张图，单张 16 MiB、ZIP 总量 2 GiB；大文件受设备内存与浏览器存储空间影响，手机可能需要等待。ZIP 使用标准“存储”模式装入原图，不二次压缩、不重新编码图片；请勿解压修改后再压缩回去。图片格式同下方单库备份范围。

导入先检查文件，再预览；选定的新增图片全部验证完才统一写入。相同图片和相同调整跳过，不同调整保留副本；不会清空已有图库。保留的待关联库也包含在下次全量导出中。

更新时把交付文件夹里的**全部文件**上传到仓库根目录，特别是 `all-backup.mjs`、`archive-zip.mjs` 和原有两个 core/backup 模块，不要只换 index.js。下面的 1.3.1 单角色功能仍然保留。

## 1.3.1：头像库文件导入 / 导出

基于 1.3.0，只新增本地图库备份，不含 WebDAV、GitHub 同步或服务端插件。

1. 三击头像，或从魔法棒打开对应头像库。
2. 展开 **头像库导入 / 导出**，点击 **导出当前图库**。
3. 浏览器下载一个 `.stafe.json` 文件。把文件传到另一设备。
4. 在另一设备打开目标 char 或 user 的头像库，点击 **导入图库备份**，选择文件并确认。

备份包含当前图库全部原图及每张图的位置、缩放、360°旋转、饱和度。图片不会重新压缩或裁切。导入只合并到当前选中的图库，不清空、不自动换头像，不覆盖轮换设置和计数；导入的新图片会参与该图库已开启的轮换。

同图同调整会跳过重复项；不同调整保留副本。首次导入后可以手动点击“使用这张”。文件内不包含聊天正文、令牌或其他角色的图库，也不是完整酒馆备份。

支持 PNG/JPG/WebP/GIF/AVIF/BMP。单张最多 16 MiB，单次最多 500 张、原图合计 64 MiB，备份文件最多 96 MiB。手机处理大文件可能较慢。备份内嵌原图，文件比原图总大小略大；请妥善保管，仅分享给可信的人。

无需注册账号、填密码或安装额外组件；普通 HTTP 地址也能使用。下载是否完成请以浏览器下载列表为准。SVG/HEIC 等格式不包含在本版备份支持范围内，遇到不支持的格式会明确提示，不会偷偷跳过图片。

更新时上传本文件夹**里面全部文件**到 Git 仓库根目录，包括新增的 `gallery-backup.mjs`。不要再套一层文件夹，也不要同时启用两个头像扩展副本。原有扩展位置更新即可；真实酒馆及 Termux 仍需自行试用验收。

这是一个 SillyTavern / 酒馆第三方前端扩展。长按头像可以调整显示位置、缩放比例和单图饱和度；连续三击头像会打开专属头像库，可以批量导入图片并用左右箭头随时切换。

## 功能

- **1.3.0 自动轮换**：打开 char 的头像库 → 展开“此角色的自动轮换” → 勾选开启、填写回复条数、选择顺序循环或随机不重复。设置立即保存，默认关闭，每张角色卡独立，user 不参与。少于两张图片不切换。
- 只计新增且完成的 char 回复。重新生成、左右切换已有回复、续写、开场白、刷新和中止不计数。计数和轮换设置随角色保存，同一角色的不同聊天共用该计数。原生群聊暂停自动轮换；单张多人角色卡可使用。
- 仅使用该 char 的头像库。每张图片分别记住位置、缩放、旋转、饱和度。旧版共用取景只迁移给升级时正在使用的图片；其他图片第一次使用需要自行调整。
- 手动点击“使用这张”或修改轮换设置会重新计数；关闭轮换保留当前头像。面板打开时先不换图，达到条数后会等关闭面板再换一次，避免打断调整。
- 自动轮换沿用手动换图的酒馆头像接口，会更新当前角色卡的头像文件；不是逐条历史消息绑定头像，原始图库文件不修改。图库保存在当前浏览器，请勿清除此站点数据。
- **上传更新请包含新增的 `cycle-core.mjs`**。未检测到所需宿主事件时只停用自动轮换，不影响原有手动功能。源码核对及验证范围见 `DEVELOPMENT.md`。

- 扩展设置中可勾选“在魔法棒菜单显示头像工具”（默认开启），单独控制菜单入口，选择会保存。

- 点击输入框旁的魔杖 → 头像工具 → 选择用户或角色 → 调整头像／头像库。头像被装饰挡住或手势关闭时也能使用；需当前聊天有头像消息。上传更新时请包含新增的 `tools.html`。

- 支持 0–360° 旋转、实时预览和恢复角度；旋转仅改变框内画面，原图文件不变。斜转后边角可能露出框内背景，可配合放大调整。
- 动图在非零角度旋转时显示静态画面，恢复 0° 后恢复原有显示。

- 扩展设置提供“启用长按调整”和“启用三击头像库”两个独立开关；可单独开启任一手势，关闭后已保存的位置、缩放和颜色继续生效。
- 放大画面时保留主题原来的圆形、圆角和遮罩，头像外框不随画面缩放。

- 手机触摸和电脑鼠标都支持长按。
- 只有按在头像实际显示范围附近才会触发调整；长按正文仍可正常选择、复制文字。
- 即使美化主题在头像上覆盖了外框、遮罩或装饰层，长按这些外层也能识别真正头像。
- 连续三击角色或用户头像会打开对应的头像库。
- 支持一次选择多张图片导入，中间显示大图，用左右箭头翻看。
- 点“使用这张”才会替换当前头像，不改动角色卡的其它资料。
- 第一次打开空头像库时，会自动保存一份当前头像，方便随时切回。
- 按头像图片分别保存位置，切换聊天或重新加载后仍然有效。
- 同一头像在聊天区和角色列表中会同步更新。
- 编辑时沿用当前头像框的长宽比例、圆角、裁剪和遮罩效果。
- 每个头像可在 50%–300% 之间独立缩放，并与取景位置一起保存。
- 每张图片可在 0%–300% 之间独立调整饱和度：0% 为黑白，100% 恢复原图颜色，提高数值可抵消部分主题的低饱和效果。
- 饱和度只作为浏览器显示设置保存，不会改写图片文件，也不会影响头像库里的其它图片。
- user 头像切换时会生成不变形的 2:3 等比铺满图，因此默认 100% 一打开就会填满头像框，不被后端 400×600 强制拉伸。
- 缩小到 100% 以下时，使用单张图片从“铺满”逐渐过渡到“完整显示”，不再叠加重复头像填充边缘。图片小于头像框时会露出框内背景；头像 `src` 不变。
- 不裁切、不压缩、不覆盖原头像文件。
- 不读取聊天内容；只有点“使用这张”时才调用酒馆自身的头像接口。

## 安装

### 方法一：复制文件夹

1. 解压后保留文件夹名 sillytavern-avatar-focus。
2. 将整个文件夹复制到：
   SillyTavern/public/scripts/extensions/third-party/
3. 重新加载酒馆页面。
4. 打开“扩展”，确认“头像取景调整”已经启用。

### 方法二：Git 仓库安装（推荐）

将这个文件夹单独发布为 Git 仓库后，在酒馆中打开：

扩展 → 安装扩展 → 粘贴仓库地址

仓库根目录必须直接包含 manifest.json、index.js、style.css 等文件，不能在仓库外面再多套一层目录。

## 使用

1. 在聊天消息或角色列表里按住头像约 0.45 秒。
2. 出现调整窗口后，直接拖动头像；也可以用三个滑杆调整缩放、横向位置和纵向位置。
3. 点“保存”。
4. 如果不想保留改动，点“取消”；点“恢复居中”可快速回到 50% / 50%。

连续快速点击同一个头像三次，会打开该角色或用户的头像库：

- 点“批量导入图片”，可以一次选中多张图片。
- 用左右箭头或在大图上左右滑动翻看头像，点“使用这张”完成切换。
- 删除头像库里的图片不会还原当前已经显示的头像。

头像库使用浏览器 IndexedDB 保存，因此刷新页面后仍然存在，但只属于当前浏览器；清除该酒馆站点的数据会同时清除头像库。为了区分单击和三击，启用三击功能后，头像原本的单击动作会等待约 0.42 秒再执行。

## 兼容性

扩展使用酒馆当前的 avatar 图片结构、extension_settings 和 edit-avatar 接口，适配较新的标准 SillyTavern 前端及基于该前端的 TauriTavern。若某个主题完全不用 img 元素显示头像，或将头像画在 canvas 中，该主题无法由本扩展调整。

Termux 中通过手机浏览器访问时，调整窗口会按 visualViewport 的实际可见高度显示，避免浏览器地址栏遮住底部按钮。
