# 头像取景调整

这是一个 SillyTavern / 酒馆第三方前端扩展。长按聊天区或角色列表中的头像，可以调整脸部在头像框里的显示位置；连续三击头像，可以直接选择新图片并替换头像。

## 功能

- 手机触摸和电脑鼠标都支持长按。
- 即使美化主题在头像上覆盖了外框、遮罩或装饰层，长按这些外层也能识别真正头像。
- 连续三击角色头像可直接选择图片并写回角色卡，不改动角色的其它资料。
- 连续三击用户头像会调用酒馆自带的用户头像上传与裁剪流程。
- 按头像图片分别保存位置，切换聊天或重新加载后仍然有效。
- 同一头像在聊天区和角色列表中会同步更新。
- 编辑时沿用当前头像框的长宽比例、圆角、裁剪和遮罩效果。
- 不裁切、不压缩、不覆盖原头像文件。
- 不读取聊天内容，也不发送任何网络请求。

## 安装

### 方法一：复制文件夹

1. 解压后保留文件夹名 sillytavern-avatar-focus。
2. 将整个文件夹复制到：
   SillyTavern/public/scripts/extensions/third-party/
3. 重新加载酒馆页面。
4. 打开“扩展”，确认“头像取景调整”已经启用。

### 方法二：Git 仓库安装（推荐）

将这个文件夹单独发布为 Git 仓库后，在酒馆中打开：

扩展 → 安装扩展 → 粘贴仓库地址

仓库根目录必须直接包含 manifest.json、index.js、style.css 等文件，不能在仓库外面再多套一层目录。

## 使用

1. 在聊天消息或角色列表里按住头像约 0.45 秒。
2. 出现调整窗口后，直接拖动头像；也可以用两个滑杆精调。
3. 点“保存”。
4. 如果不想保留改动，点“取消”；点“恢复居中”可快速回到 50% / 50%。

连续快速点击同一个头像三次，会立即打开图片选择器。选择图片后：

- 角色头像：通过 /api/characters/edit-avatar 只替换头像。
- 用户头像：通过酒馆自带的用户头像上传流程替换。

为了区分单击和三击，启用三击功能后，头像原本的单击动作会等待约 0.42 秒再执行。扩展设置中可以分别关闭长按/三击功能、更改长按时间，也能让所有头像一次性恢复主题默认位置。

## 兼容性

扩展使用酒馆当前的 avatar 图片结构、extension_settings 和 edit-avatar 接口，适配较新的标准 SillyTavern 前端及基于该前端的 TauriTavern。若某个主题完全不用 img 元素显示头像，或将头像画在 canvas 中，该主题无法由本扩展调整。

Termux 中通过手机浏览器访问时，调整窗口会按 visualViewport 的实际可见高度显示，避免浏览器地址栏遮住底部按钮。
